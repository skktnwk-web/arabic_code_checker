About: This tool is designed to check the Unicode code points of Arabic-script characters for bibliographic cataloging. It can be used to verify text copied from OCR results or websites.

It also provides a function to add Arabic diacritics to text. OCR may omit diacritics such as vowel marks and shadda, which can lead to inaccurate romanization when the text is processed by generative AI. This function helps restore missing diacritics before generating romanization.

このツールは、書誌目録作成のためにアラビア文字系文字のUnicodeコードポイントを確認する目的で設計されています。OCR結果やウェブサイトからコピーしたテキストの確認に利用できます。

また、テキストにアラビア語の発音記号を追加する機能もあります。OCRでは母音記号やシャッダなどが省略されることがあり、そのまま生成AIで処理するとローマ字転写が不正確になる場合があります。この機能を使うことで、ローマ字転写を生成する前に欠落した発音記号を補えます。

Disclaimer: This tool does not necessarily detect all relevant Unicode code points or character patterns. Its detection rules are not intended to be comprehensive, and a character or pattern that is not detected should not necessarily be considered correct or problem-free. The results are provided for reference purposes only. Please verify the Unicode code points independently before relying on the results.

このツールでは、関連するUnicodeコードポイントや文字パターンをすべて検出できるとは限りません。検出ルールは網羅的なものではなく、検出されなかった文字やパターンが必ずしも正しい、または問題がないとは限りません。結果は参考情報としてのみご利用ください。結果を信頼する前に、Unicodeコードポイントを個別に確認してください。
